# 2x2 Traffic Network

## Purpose

This directory defines the baseline physical road network used by
the traffic-control project.

## Topology

The network contains four intersections:

- N1: northwest
- N2: northeast
- N3: southwest
- N4: southeast

The physical topology is:

```text
N1 -------- N2
|            |
|            |
|            |
N3 -------- N4
